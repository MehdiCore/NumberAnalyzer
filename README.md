🔢 Number Analyzer
A simple Python program that analyzes a set of numbers and calculates their average, maximum, and minimum values.

✨ Features:

- 📊 Calculate average
- 🔼 Find maximum value
- 🔽 Find minimum value
- 🖥️ Simple command-line interface
- 🚫 No external dependencies

🛠️ Technologies:

- Python 3

📁 Project Structure:
NumberAnalyzer/
├── images/
│ └── output.png
├── main.py
└── README.md

🚀 Usage:

- Run the program with python main.py
- Then enter the number of values and the numbers you want to analyze.
- Example Output

- average number: 30.0
- maximum number: 50.0
- minimum number: 10.0
